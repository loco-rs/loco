### `IsolationLevel`

- `variant` **ReadCommitted** — Each consistent read, even within the same transaction, sets and reads its own fresh snapshot
- `variant` **ReadUncommitted** — SELECT statements are performed in a nonlocking fashion, but a possible earlier version of a row might be used
- `variant` **RepeatableRead** — Consistent reads within the same transaction read the snapshot established by the first read
- `variant` **Serializable** — All statements of the current transaction can only see rows committed before the first query or data-modification statement was executed in this transaction
