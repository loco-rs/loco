A quick tour with Loco

In a few minutes you'll scaffold a real app, add a model, and hit a working JSON endpoint — the whole batteries-included loop.

Create an app#

Install the CLI and generate a new project. Loco writes a complete app — database, auth, background jobs, and tests — wired together and ready to run.

terminal⧉ copy
$ cargo install loco
$ loco new my_app
✓ generated 34 files · auth · migrations · workers
$ cd my_app && cargo loco start
◆
Following Rails? If you've used rails new, this will feel familiar — the concepts carry over, adapted to idiomatic Rust.

Add a model#

Generate a model and its migration in one line. The DSL mirrors your columns; the generated code is yours to edit.

terminal⧉ copy
$ loco generate model article title:string content:text

Hit an endpoint#

Controllers are plain functions returning a Result<Response>. Register them in routes() and you're serving JSON.

src/controllers/articles.rs⧉ copy
use loco_rs::prelude::*;
use crate::models::_entities::articles;

pub async fn list(State(ctx): State<AppContext>) -> Result<Response> {
    let items = articles::Entity::find().all(&ctx.db).await?;
    format::json(items)
}

That's the whole loop: new → generate → serve. Next, we'll add background jobs and tests.
