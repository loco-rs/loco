# Loco 1.0 Docs — Foundation & Reference Tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Docs pages are additionally authored with the `documentation-writer` (Diátaxis) skill.

**Goal:** Stand up the "verified-docs" spine (a committed, CI-compiled demo app + blocking-capable snipdoc) and author the 10 Reference pages of the Pure-Diátaxis 1.0 site, each claim traced to code.

**Architecture:** A dogfooded `examples/demo` Loco app becomes a workspace member so CI compiles every app-level snippet; `snipdoc` pulls snippets from it and from crate source; the Zola site is re-scaffolded into four Diátaxis quadrants. Reference pages are near-transcriptions of the verified inventories at `docs/superpowers/specs/2026-07-03-loco-1.0-inventory/`.

**Tech Stack:** Rust (edition 2024, rustc 1.94, Sea-ORM 2.0-rc, sqlx 0.9), Zola static site, snipdoc (`--features exec`), the loco-rs `xtask` (`llms-check`), `documentation-writer` skill.

## Global Constraints

- Target version: **1.0.0** (major). Doc version markers say `1.0`.
- **Only verified docs:** every claim traces to a `file:line` in the inventory or repo; every code sample compiles (demo app, doctest, or snipdoc exec).
- **Local commits only** on branch `release/1.0.0`; never push/publish.
- Pure **Diátaxis**: each page is exactly one of Tutorial / How-to / Reference / Explanation.
- Ground truth: `docs/superpowers/specs/2026-07-03-loco-1.0-inventory/` (`00-MASTER-coverage-matrix.md` + `01`–`08`). Re-verify against `HEAD` at authoring time.
- Headline 1.0 facts (fix everywhere): `int`→i64/BIGINT; i64 PKs; priority queues + `perform_later`→job-id `String` + Redis supported; mailer TLS modes override `secure`; `auth_jwt` (HS512, base64 secret, multi-location); error enum narrowed (`#[non_exhaustive]`); edition-2024 `set_var` needs `unsafe`; `embedded_assets` swaps engines.

## PHASE 2 — Reference tier (10 pages)

Each Reference page is one task with the same shape. **Per-task procedure (applies to Tasks 4–13):**

1. **Author** via `documentation-writer`: declare `type = Reference`, audience = "developer building a Loco app", goal = "look up exact <X>", scope = the cited inventory section. Propose the outline (table of contents) — gate it — then write.
2. **Source:** transcribe ONLY from the cited inventory file, re-checking each `file:line` against `HEAD`. No claim without a code anchor.
3. **Snippets:** any runnable snippet is pulled via snipdoc from `examples/demo` or is a doctest; config/CLI/flag tables are transcribed verbatim from the inventory (which is code-derived).
4. **Verify:** for each page, spot-check 3 cited `file:line` anchors resolve and match; if the page shows a compilable snippet, confirm it builds.
5. **Front matter:** TOML with `title`, `description`, `weight` (page order within Reference), `template = "docs/page.html"`.
6. **Commit** the single page.
