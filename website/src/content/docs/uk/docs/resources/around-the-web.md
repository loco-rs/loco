## Екосистема

- [rhai-loco](https://docs.rs/rhai-loco/latest/rhai_loco/) - цей крейт додає підтримку скриптів [Rhai](https://rhai.rs) до [Loco](https://loco.rs)
- [loco-oauth2](https://github.com/yinho999/loco-oauth2) - Loco OAuth2 — це простий ініціалізатор OAuth2 для Loco API. Він розроблений як крихітна та проста в використанні бібліотека для впровадження OAuth2 у вашому застосунку.
