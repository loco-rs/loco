Мета: безпечно зберігати паролі при реєстрації, перевіряти їх при логіні та генерувати випадкові рядки для таких речей, як токени скидання або API-ключі.

`loco_rs::hash` обгортає Argon2id (крейт `argon2`) для хешування паролів і випадковий буквено-цифровий генератор для токенів. На відміну від механізму JWT-автентифікації, цей модуль **не** обмежений фічами — він завжди доступний, без жодної Cargo-фічі для увімкнення.

## Хешуємо пароль при реєстрації

```rust
use loco_rs::hash;

let hashed = hash::hash_password("the-users-plaintext-password")?;
// зберігайте `hashed` у рядку користувача, але ніколи — відкритий пароль
```

`hash_password` використовує Argon2id зі свіжою випадковою сіллю (`OsRng`) при кожному виклику, тож хешування одного пароля двічі дає два різні рядки — це очікувано; порівняння виконує `verify_password` (нижче). Вона повертає `Result<String>` Loco; невдача хешування проявляється як `Error::Message` через `Error::msg`.

## Перевіряємо пароль при логіні

```rust
use loco_rs::hash;

if hash::verify_password(&submitted_password, &user.password_hash) {
    // облікові дані чинні
} else {
    // відхиляємо логін
}
```

`verify_password` повертає звичайний `bool`, а не `Result` — вона повертає `false` і для «неправильного пароля», і для «malformed/чужого рядка хешу», тож поганий рядок у базі даних призводить до безпечної відмови (fail closed), а не до помилки, яку довелося б не забути обробити. Вона позначена `#[must_use]`, тож компілятор видасть попередження, якщо ви проігноруєте результат.

## Генеруємо випадкові токени

```rust
use loco_rs::hash;

let reset_token = hash::random_string(32);
let api_key = hash::random_string(40);
```

`random_string(length)` повертає буквено-цифровий рядок рівно з `length` символів, придатний для токенів скидання пароля або персональних API-ключів — як підключити згенерований ключ до `Authenticable::find_by_api_key`, дивіться в [Захищаємо маршрут за допомогою API-ключа](/uk/docs/how-to/api-key-auth/).

## Перевіряємо, що працює

Швидкий прохід туди-назад у тесті або тимчасовій бинарці:

```rust
let pass = "correct horse battery staple";
let hashed = hash::hash_password(pass)?;

assert!(hash::verify_password(pass, &hashed));
assert!(!hash::verify_password("wrong password", &hashed));
```

## Пов'язане

- [Захищаємо маршрут за допомогою API-ключа](/uk/docs/how-to/api-key-auth/) — використайте `random_string`, щоб зкарбувати ключ, і `find_by_api_key`, щоб його знайти.
- [Захищаємо маршрут за допомогою JWT](/uk/docs/how-to/jwt-auth/) — видайте токен, щойно `verify_password` підтвердить логін.
- [Довідник моделі помилок](/uk/docs/reference/errors/) — як `Error::msg`/`Error::Message` вписуються в тип помилок крейта.
