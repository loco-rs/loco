Loco — це **фреймворк для одного розробника на Rust** — «батарейки в комплекті», натхненний Rails. Ця документація проведе вас від першої команди `cargo loco` аж до роботи в продакшені: моделі, контролери, фонові завдання, пошта, автентифікація та CLI, який усе це з'єднує.
